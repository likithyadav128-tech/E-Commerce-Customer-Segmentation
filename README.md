# 🛍️ E-Commerce Customer Segmentation

## 📌 Project Overview

The **E-Commerce Customer Segmentation** project uses **K-Means Clustering**, an unsupervised machine learning algorithm, to group customers based on their purchasing behavior. The project helps businesses understand different customer segments and enables targeted marketing strategies.

The project includes data cleaning, exploratory data analysis (EDA), customer segmentation using K-Means, SQL analysis, and an interactive Power BI dashboard.

---

# 🎯 Objectives

- Analyze customer demographics
- Identify different customer segments
- Discover high-value and low-value customers
- Perform customer segmentation using K-Means Clustering
- Build an interactive Power BI dashboard
- Generate business insights for marketing strategies
